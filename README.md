# Сайт-портфолио

Простой адаптивный сайт-портфолио, созданный с использованием HTML, CSS и JavaScript.

## Особенности

- Адаптивный дизайн (мобильные устройства, планшеты, десктопы)
- Плавная прокрутка до разделов
- Анимации при прокрутке
- Форма обратной связи с валидацией
- Современный и чистый дизайн

## Структура проекта

```
.
├── index.html         # Основной HTML файл
├── css/
│   └── style.css      # Стили CSS
├── js/
│   └── main.js        # JavaScript код
└── images/            # Изображения проектов
    ├── project1.jpg
    ├── project2.jpg
    └── project3.jpg
```

## Запуск проекта

Просто откройте файл `index.html` в любом современном веб-браузере.

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, Медиа-запросы)
- JavaScript (ES6+)
- Intersection Observer API для анимаций прокрутки
